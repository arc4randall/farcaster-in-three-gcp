三条命令跑起 Farcaster（Google Cloud）

本页为机器辅助翻译的精简版，如有出入以英文版为准。欢迎提交 PR 修正。

完成后你会有一台自己付费的虚拟机，上面运行 Snapchain 只读节点（read node），以及一个从该节点读取数据、通过该节点发帖的小型网页客户端。不需要任何 API key。

快速开始

在 Cloud Shell（已登录 gcloud）或任何配置好 gcloud 且已启用结算的项目中运行：

git clone https://github.com/arc4randall/farcaster-in-three-gcp && cd farcaster-in-three-gcp
  1. 创建算力（e2-standard-4、2 TB pd-balanced 磁盘、开放 3382/udp 防火墙）：
    ./provision.sh
  2. 启动 Snapchain 只读节点（Docker，镜像固定为 farcasterxyz/snapchain:0.14.3）：
    ./node.sh
    首次启动会下载快照并追块，需要数小时。
  3. 运行客户端：首次运行会要求输入助记词并注册 app key，然后打开 localhost:3000：
    ./client.sh

删除全部资源：gcloud compute instances delete fc-node --zone us-central1-a

输入助记词之前请先读这里。
  • 助记词等于账户的全部控制权：可以转走 FID、修改恢复地址、增删所有 key。请像对待 rm -rf / 一样谨慎。
  • 请使用测试账户，不要用主账户。
  • 只把助记词交给你读过代码或信任其开发者的软件。运行前请阅读 client/setup.mjs（约 100 行）。
  • 能用委托签名授权（在钱包或已有客户端里批准请求）时优先使用，这样助记词不会离开原处。
  • 本客户端：setup.mjs 在你自己的虚拟机上从终端读取助记词（不回显），只在内存中签两条 EIP-712 消息后退出；不写盘、不发送给其他服务器、不进入网页界面。只保存新生成的 app key（权限 600）。

核心概念

FID

Farcaster 账户就是一个数字 FID，由 Optimism 上的 IdRegistry 合约发放。用户名只是指向 FID 的另一层。

托管地址（custody address）

拥有该 FID 的以太坊地址，由助记词派生。它不直接签发帖子，而是授权其他 key 代为签名，也可以转移 FID。

App key（签名者）

Ed25519 密钥对，应用持有私钥并用它签名每一条消息。添加 key 时，请求方应用的 FID 会签一个 SignedKeyRequest，其中的 requestFid 与 key 一起保存，因此可以据此判断任意一条 cast 来自哪个客户端。

两种添加方式：免 gas 的 KEY_ADD（FIP-272，自引擎 V16 起上线，本项目默认）——无需交易，带权限范围（scopes）和最长 90 天的滑动有效期，需要使用 currentUserNonce + 1；以及链上 KeyGateway.add（Optimism，一笔交易），用 ./client.sh --onchain 启用。

Snapchain 消息

所有操作都是 protobuf Message：包含 MessageData（类型、FID、自 2021-01-01 起的秒数时间戳、正文）、截断为 20 字节的 BLAKE3 哈希、Ed25519 签名和签名者公钥。

只读节点与验证者

所有节点运行同一程序。主网少数验证者负责出块投票；任何人都可以运行只读节点：从对等节点获取已决定的区块、校验后应用，并在 3381（HTTP）和 3383（gRPC）提供 API。

存储租金

账户需在 Optimism 的 StorageRegistry 租用存储单元，一个单元有效期一年，每种消息有上限，超出后最旧的消息被裁剪。查询：curl -s "localhost:3381/v1/storageLimitsByFid?fid=你的FID"。没有存储的 FID 发出的消息会被拒绝。

一条写入如何到达链上

  1. 客户端构造并签名消息，POST 到你自己节点的 /v1/submitMessage。
  2. 节点按 FID 分配分片并校验（签名、key、权限、存储）。
  3. 只读节点没有内存池，只把消息通过 3382/udp 的 mempool gossip 主题转发出去。
  4. 验证者从 gossip 收到后放入内存池并打包进区块。
  5. 你的节点同步到该区块后，消息即可读取。

因此 submitMessage 返回 200 只表示“有效并已转发”，不表示已上链。客户端发帖后会轮询 /v1/castById 确认。

费用

us-central1 按需价格：VM 约 $98/月，2000 GB 磁盘约 $200/月，合计约每天 $10。用完请删除 VM。

故障排查

  • “owns no FID”：试试 ACCOUNT_INDEX=1。
  • KEY_ADD nonce 错误：重新运行 ./client.sh。
  • 发帖成功但看不到：gossip 丢失，重发；检查 3382/udp 是否开放。
  • 信息流为空：节点仍在同步（看 blockDelay）。
